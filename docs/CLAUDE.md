# docs 디렉토리 관리 규칙

## 파일 명명 규칙

```
{NN}_{TITLE}.md
```

- `NN`: 두 자리 숫자 (01–99)
- `_`: 숫자와 제목 구분자
- `TITLE`: 대문자 영문 또는 한국어

예시: `00_ARCHITECTURE.md`, `30_TESTING.md`

---

## 카테고리별 번호 범위

| 범위 | 카테고리 |
|------|---------|
| `00–09` | 아키텍처 / 전체 설계 |
| `10–19` | 개발 환경 / 가이드 |
| `20–29` | API / 인터페이스 명세 |
| `30–39` | 테스트 |
| `40–49` | 배포 / 운영 |
| `50–59` | 작업 히스토리 |

---

## 번호 관리 정책

1. 번호는 각 카테고리 내에서 순차 증가.
2. 파일 삭제 시 번호 재사용 금지. Gap 허용.
3. 파일 추가/삭제/이름 변경 시 `README.md` index 반드시 업데이트.
4. 번호 재배치(renumber)는 명시적 요청 시에만 수행.

---
